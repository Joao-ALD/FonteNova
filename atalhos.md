# ⌨️ Atalhos Úteis para Desenvolvedores (Windows + VS Code)

---

## 🪟 Atalhos Essenciais do Windows para Desenvolvedores

| Atalho | Ação |
|--------|------|
| `Win + E` | Abrir o Explorador de Arquivos |
| `Win + D` | Mostrar ou ocultar a área de trabalho |
| `Win + R` | Abrir o diálogo "Executar" |
| `Win + S` | Abrir a busca do Windows |
| `Win + .` | Abrir o seletor de emojis 😎 |
| `Alt + Tab` | Alternar entre janelas abertas |
| `Win + Ctrl + D` | Criar uma nova área de trabalho virtual |
| `Win + Ctrl + ← / →` | Alternar entre áreas de trabalho virtuais |
| `Win + L` | Bloquear o computador |
| `Ctrl + Shift + Esc` | Abrir o Gerenciador de Tarefas diretamente |
| `Ctrl + C`, `Ctrl + V`, `Ctrl + X` | Copiar, colar e recortar |
| `Alt + F4` | Fechar a janela atual |

---

## 🛠️ Atalhos Mais Úteis no **VS Code**

### 📁 Navegação e Arquivos

| Atalho | Ação |
|--------|------|
| `Ctrl + P` | Abrir arquivos rapidamente (Go to File) |
| `Ctrl + Shift + E` | Alternar para o Explorador lateral |
| `Ctrl + Shift + F` | Buscar globalmente no projeto |
| `Ctrl + B` | Mostrar/Ocultar a barra lateral |
| `Ctrl + Tab` | Alternar entre arquivos abertos |
| `Ctrl + W` | Fechar a aba atual |

### 💻 Terminal

| Atalho | Ação |
|--------|------|
| `Ctrl + '` (aspas simples) | Abrir/Fechar o terminal integrado |
| `Ctrl + Shift + '` | Criar um novo terminal integrado |
| `Ctrl + Shift + C` | Abrir o terminal externo padrão |

### 🧠 Código e Edição

| Atalho | Ação |
|--------|------|
| `Ctrl + /` | Comentar/Descomentar linha ou seleção |
| `Alt + ↑ / ↓` | Mover linha ou bloco de código para cima/baixo |
| `Shift + Alt + ↓ / ↑` | Duplicar linha ou bloco de código |
| `Ctrl + Space` | Sugerir autocompletar (IntelliSense) |
| `Ctrl + Shift + L` | Selecionar todas as ocorrências da palavra selecionada |
| `Ctrl + D` | Selecionar a próxima ocorrência da palavra selecionada |
| `Ctrl + Shift + K` | Excluir linha atual |
| `Ctrl + Z / Ctrl + Y` | Desfazer / Refazer |

### 🖥️ Interface e Layout

| Atalho | Ação |
|--------|------|
| `Ctrl + Shift + P` ou `F1` | Acessar a paleta de comandos |
| `Ctrl + \` | Dividir o editor em painéis |
| `Ctrl + 1 / 2 / 3` | Focar no primeiro, segundo ou terceiro painel |
| `Ctrl + K Z` | Entrar em modo Zen (foco total no código) |
| `F11` | Tela cheia |
| `Ctrl + Shift + X` | Abrir o gerenciador de extensões |

### 🧪 Debug

| Atalho | Ação |
|--------|------|
| `F5` | Iniciar depuração |
| `Shift + F5` | Parar depuração |
| `F9` | Adicionar/Remover breakpoint |
| `F10` | Avançar para a próxima linha (Step Over) |
| `F11` | Entrar na função (Step Into) |
| `Shift + F11` | Sair da função (Step Out) |

---

## 🔄 Dicas Extras

- Você pode **personalizar todos os atalhos**: `File → Preferences → Keyboard Shortcuts` ou `Ctrl + K Ctrl + S`
- Use a extensão **"Command Runner"** para criar atalhos customizados com scripts
- Atalhos podem variar um pouco entre Windows, Linux e macOS

---

## 🧭 Resumo Rápido

- `Ctrl + P`: Abrir arquivos
- `Ctrl + /`: Comentar código
- `Ctrl + '` : Terminal integrado
- `Ctrl + Shift + P`: Paleta de comandos
- `Alt + ↑ / ↓`: Mover linhas
- `Ctrl + Shift + L`: Selecionar todas as ocorrências
- `Ctrl + B`: Mostrar/ocultar barra lateral
